# Card Studio · 闪卡工坊

多视角 3D 立体旋转闪光卡生成器（不依赖大语言模型）。

## 项目目标

用户上传 N 张同一角色/物体的不同视角位图，程序自动完成：

1. 自动抠图（透明背景）
2. 分层合成（主体 + 背景 + 烫金/描边文字）
3. 生成 3D 旋转查看器：连续旋转，转到哪个角度显示对应视角图（相邻帧 alpha 平滑过渡）
4. 导出本地产物（HTML + 图片 + 配置）

## 已确认技术决策（2026-09-09）

| 项 | 决策 |
| --- | --- |
| 输入形态 | B 方案：N 张视角位图（N≥1，按文件名排序均匀分布 0°~360°） |
| 抠图 | ONNX Runtime Web 跑 U²-Net 模型（WASM/WebGPU，前端闭环，质量与 rembg 同模型一致） |
| 合成 | Canvas2D（统一画布、渐变背景、烫金/描边文字、PNG 导出） |
| 3D 渲染 | Three.js + 自写拖拽交互（视角纹理切换 + 相邻帧混合） |
| 应用壳 | Tauri v2（桌面 Windows/macOS/Linux + 移动 iOS/Android，后续阶段） |
| 交付 | 第一阶段为纯 Web 版（浏览器直接运行）；后续套 Tauri 壳 |

关键约束：**全程无 LLM、无 Python 依赖**（抠图/合成/渲染全部在 WebView 内完成，以支持 iOS/Android 移动端）。

1. **第一阶段（已完成 2026-09-09，网页版持续完善中）**：纯 Web 版——选图 → 自动抠图 → 分层合成 → 3D 旋转查看 → 导出，功能闭环，已通过端到端测试

## 运行方式

```bash
# 方式一：双击 start.bat（自动检测 Node 并启动）
# 方式二：命令行
cd src-web
node server.js
# 浏览器打开 http://127.0.0.1:4173/
```

使用步骤：上传 N 张视角图（第 1 张 = 0°，其余均匀分布，可逐张自定义角度）→ 选择抠图方式与模型 → 填写卡面参数（含主体大小缩放）→ 点「生成闪卡」→ 右侧拖拽/按键/跳转按钮旋转查看 → 导出 PNG（文件名带角度）/ config.json。

本地依赖已就位（无需联网）：`src-web/vendor/`（three.js、onnxruntime-web 及 wasm）、`assets/models/`。示例视角图在 `assets/samples/`。

## 抠图模型（2026-09-09 更新）

| 模型 | 大小 | 输入 | 定位 |
| --- | --- | --- | --- |
| MODNet FP32 | 25.9MB | 256×256 | 通用平衡（默认） |
| MODNet INT8 | 6.6MB | 256×256 | 快速/移动端推荐 |
| U²-Net 便携（u2netp） | 4.7MB | 320×320 | 轻量通用，比 MODNet 更稳 |
| ISNet-Anime | 176MB | 1024×1024 | 动漫立绘最佳（下载中） |

移动端 CPU 可行性：Web 版 WASM CPU 跑 MODNet INT8 足够；Tauri 移动端可升级原生 ONNX Runtime（自动 CoreML/NNAPI 加速）。

## 体验与工程备忘（2026-09-09）

- 180° 背面黑屏根因：PlaneGeometry 默认单面渲染 → 已改 `THREE.DoubleSide`，0-360° 全程可见。
- 服务器已加 `Cache-Control: no-cache`（html/js/css/json），改代码后刷新即生效；图片/模型走长缓存。
- 模型按路径独立缓存，切换模型自动重新加载（修复 session 单例导致"换模型不生效"）。
- 体验增强：生成进度条、导出文件名带角度、主体大小滑块、键盘 ←/→ 旋转（6°/格）、0/90/180/270° 跳转按钮 + 自定义角度跳转、逐张删除 + 清空图片、导出状态提示。
